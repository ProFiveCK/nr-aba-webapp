## Users and sign-in emails

Administration → User Management lists people by the job they do. **Add user** and **Edit** start from an **Access** choice (for example Staff member, Leave approver, Treasury reviewer); **Advanced access** holds the role and individual capabilities for unusual combinations.

An account's sign-in email is changed with **Change…** beside it (or the row menu). The change signs the person out everywhere, cancels password-reset and activation links already sent, removes the Google link so it can be re-made on the new address, updates a linked staff record's contact email, and notifies both addresses. The reason is audited.
